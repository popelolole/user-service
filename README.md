# User Service

User service for the
[Healthcare Microservices Platform](https://github.com/popelolole/healthcare-microservices-platform).

Handles user lookup and the local login flow used during the earlier stages
of the project. Authentication for most other services was later moved to
Keycloak.

## Tech

Java · Spring Boot · Spring Security · Hibernate/JPA · MySQL · Docker · Kubernetes

## CI/CD

GitHub Actions builds and publishes the Docker image.
